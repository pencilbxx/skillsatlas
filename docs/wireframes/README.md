# Demo wireframes

Clickable four-screen mock for the 90-second pitch. Visual language matches the Ireland evidence atlas ([Manus report](https://ireland-skil-q5sln9qn.manus.space)): DM Serif Display, Manrope, coral accent, navy, OBSERVED/REPORTED chips.

This is a **wireframe**, not the Next.js app. Course names are labelled **example** until `data/courses/` is seeded. Paper Desktop was not connected in this session, so this HTML is the team artefact.

## Live URL

https://skillsatlas.vercel.app — Vercel project `skillsatlas` on Andrew’s Hobby account. Same account as Ravens Point.

## Open in Cursor’s browser

1. Press **Ctrl+Shift+P**
2. Type **Simple Browser: Show** and press Enter
3. Paste `https://skillsatlas.vercel.app` (or local `http://127.0.0.1:8765/demo.html` if the local server is running)

You can also click the Browser tab in Cursor and paste the URL in the address bar. Do not use `file://` — Cursor’s browser will not open a local file that way.

## Open for the team (Chrome)

1. Open https://skillsatlas.vercel.app
2. Press **F11** for full screen.
3. Walk **1 → 4** with the keys, or click the coral buttons. The navy bar at the bottom is the spoken line from `docs/demo-script.md`.

| Key | Screen | What to click |
| --- | --- | --- |
| 1 | Problem | Same CV, this time as evidence |
| 2 | Evidence | Confirm these lines → Answer (or Skip) twice → See two routes |
| 3 | Routes | Choose this path (goes to the board) |
| 4 | Board | Flip Phone / First / Panel and Recruiter / Hiring manager — questions change, STAR stays |
