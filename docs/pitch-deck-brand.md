# SkillsAtlas — pitch deck brand

For Bridget’s Hub slides. Match the live demo and film. Do not use this file for spoken script or slide wording.

**Slide words:** only the **On the slide** lines in `docs/pitch-slide-text.md`.

**Live look to match:** https://skillsatlas.vercel.app

## Names on slides

| Use this | Do not use |
| --- | --- |
| **SkillsAtlas** | Skills Atlas, RedeployMate (Skills Atlas) |
| **SkillsAtlas Interview Board** | cheat-board, evidence pack, board they wrote |
| **two credible role routes** | top jobs, ranked matches, jobs available now |
| **clickable prototype** | live AI product, production system |
| **illustrative learning option** | real course, guaranteed place |
| **question example** | predicted question |
| RedeployMate (team name only, if needed) | RedeployMate as the product title |

Hook, one line:

> **A list gives you options. SkillsAtlas gives you proof.**

On Slide 1, set *proof* in italic coral.

## Type

| Role | Font |
| --- | --- |
| Product name, slide titles, hook | **DM Serif Display** |
| Body, labels, captions, team names | **Manrope** 500–700 |

Google Fonts (install in PowerPoint / Keynote, or paste into Gamma / Canva):

https://fonts.googleapis.com/css2?family=DM+Serif+Display:ital@0;1&family=Manrope:wght@400;500;600;700;800&display=swap

Fallback if a tool cannot load them: Georgia for titles, Arial for body.

Keep type large. If a line does not fit, cut words with the team — do not shrink the title.

## Colour

Cream slides. Navy for dark holding slides (film and live demo). Coral as the only loud accent.

| Token | Hex | On the deck |
| --- | --- | --- |
| Cream | `#F7F4EF` | Default slide background |
| Card | `#FFFCFA` | Panels on cream |
| Navy | `#102B3F` | Dark slides, header mark contrast, film/demo holding slides |
| Navy ink | `#183143` | Body text on cream |
| Coral | `#ED6A4A` | Accent, *proof*, primary emphasis |
| Teal | `#1E5D5E` | Confirmed evidence, quiet highlight |
| Muted | `#49606D` | Captions, sources, secondary labels |
| Unconfirmed | `#FFD9CF` / ink `#8B3827` | Weak CV claim such as “managed stock” |
| Border | `#D9CFC3` | Hairline rules only |

Text on navy: `#F8FAFC`. Do not put body text in coral. Do not use default PowerPoint blue, purple gradients, or stock icon packs in a different palette.

## Layout, by slide

Follow the **Picture** notes in the Team Draft. Short version:

| Slide | Look |
| --- | --- |
| 1 Hook | One large line on cream. SkillsAtlas in the corner. No statistics, no process diagram. |
| 2 Problem | Title on one side. Three missing pieces on the other: evidence, gap, next step. Warehouse line: **“managed stock.”** |
| 3 The sitting | Four words only: Confirm · Question · Two routes · Interview Board. |
| 4 Film | Existing silent film full-bleed. Tiny caption: **The map behind the sitting**. No music, no new footage. |
| 5 Live demo | Navy holding slide. Browser is the visual. URL: skillsatlas.vercel.app |
| 6 Who pays | One four-screen flow. Two host settings around it, not two products. |
| 7 Different | Short trail: CV claim → worker confirms → question → worker confirms → Board. |
| 8 Next proof | Three questions. No growth chart. No 10 → 20 → 200 traction table. |
| 9 Team | Five names, one true line each. No inflated job titles. |
| 10 Ask | Two steps: Galway → one hosted sitting. URL and one email in the corner. |

## Do not put on the deck

- A customer, pilot, signed lead, or price
- Ranked people or hiring likelihood
- WhatsApp
- A recruiter CRM-search product
- Personality tests, SWOT, or competency ladders
- The old three-week “abandoned by the office” story

The organisation hosting the sitting is the proposed payer. This is not a consumer app on the slides.
